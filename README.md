# Sahitya Pandey — Graphic Design Portfolio

A responsive, single-page portfolio starter website.

## Included
- Hero and positioning statement
- Selected work: Ubitech, Unique Seal, product catalogues, social campaigns
- Services, About, Skills and Contact sections
- Responsive mobile navigation/layout
- Links to your existing Canva portfolio, LinkedIn, GitHub and published Unique Seal blog
- No build tools required — it is a static HTML site

## Important before publishing
The portfolio artwork panels are **illustrative concept previews**, not the original client deliverables. Replace them with your actual approved designs before sharing the site publicly.

### How to replace a project preview with your real image
1. Put the image in the `assets/` folder (example: `assets/ubitech-linkedin-post.jpg`).
2. Open `index.html`.
3. Find the relevant `<div class="project-art ..."> ... </div>` and replace the inner preview with:
   `<img src="assets/ubitech-linkedin-post.jpg" alt="Ubitech LinkedIn creative" style="width:100%;height:100%;object-fit:contain">`
4. Repeat for each project, keeping the image's rights and client approvals in mind.

## Preview locally
Open `index.html` in any browser.

## Publish for free using Vercel Drop (no terminal needed)
1. Extract this ZIP on your computer.
2. Open https://vercel.com/drop and sign in/sign up.
3. Drag the **sahitya-graphic-design-portfolio** folder (or a ZIP of its contents) into the upload area.
4. Follow the prompts. Vercel will give you a public `*.vercel.app` URL.
5. Open the URL on both mobile and desktop, then share it on LinkedIn/resume.

Alternative: upload the folder to a GitHub repository and import that repository in Vercel. Static HTML needs no build command; the root directory should contain `index.html`.
